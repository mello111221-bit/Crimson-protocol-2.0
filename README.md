🔴 CRIMSON PROTOCOL

Advanced Java Survival Shooter

Welcome to CRIMSON PROTOCOL, a futuristic survival shooter built with Java 17 and Java Swing.

Fight hostile drones, survive increasingly difficult enemy waves, collect repair cells, and achieve the highest score possible.

🎮 GAME FEATURES

* 🚀 Player movement and shooting
* 🤖 Enemy drone AI
* 🌊 Increasingly difficult waves
* ❤️ Health and damage system
* 💚 Health pickups
* 💥 Particle explosion effects
* 🏆 Score tracking
* ⏸️ Pause and restart functionality
* ⚡ Boost movement
* 🎨 Custom Java2D graphics

🕹️ CONTROLS

Key	Action
W A S D	Move
Arrow Keys	Move
SPACE	Shoot
SHIFT	Boost
P	Pause / Resume
ESC	Pause
ENTER	Start / Restart

💻 REQUIREMENTS

* Java Development Kit (JDK) 17 or newer
* Windows, macOS, or Linux
* No external libraries required

⚙️ INSTALLATION

1. Download or clone this repository.
2. Extract the project files.
3. Open a terminal in the project directory.

Compile

javac -d out src/main/java/com/carter/crimson/*.java

Run

java -cp out com.carter.crimson.Game
